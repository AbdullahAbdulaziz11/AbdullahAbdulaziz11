مهتم بعلم البيانات والذكاء الاصطناعي، وأشتغل على مشاريع في التحليل، NLP، والتعلم العميق.

## أبرز مشاريعي

**YouTube Comments Analysis** — تحليل كامل لتعليقات فيديوهات يوتيوب: جمع البيانات، تنظيفها، تصنيفها، واستخراج رؤى منها.

**Geo QA Bot (المجيب الذكي)** — نظام أسئلة وأجوبة جغرافي مكاني مبني على بيانات GeoJSON وقاعدة أسئلة وأجوبة.

**Advanced Data Mining — Freight/Transport Analysis** — تحليل بيانات الشحن والنقل باستخدام تقنيات تنقيب البيانات واكتشاف القيم الشاذة.

**METR-LA Traffic Prediction (ST-LLM)** — توقع حركة المرور باستخدام الذكاء الاصطناعي على بيانات METR-LA، لوس انجلوس الامريكيه، 

**MapGPT NYC Traffic** — تطبيق ويب تفاعلي لعرض وتحليل حركة المرور في نيويورك بخرائط حية.
